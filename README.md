# بريق — واجهة متجر الجمال

واجهة عربية متجاوبة لمتجر مكياج وعناية بالبشرة، مبنية بـ React وVite. تضم صفحة رئيسية، تصنيفات، بحثاً وفرزاً، تفاصيل المنتجات، مفضلة، سلة، ونموذج طلب تجريبي. تُحفظ السلة والمفضلة في المتصفح.

## التشغيل

```bash
npm_config_cache=/workspace/.npm-cache npm ci
npm run dev
```

ثم افتح العنوان المحلي الذي يعرضه Vite. للبناء الإنتاجي:

```bash
npm run build
npm run preview
```

## قبل استقبال طلبات فعلية

المنتجات والأسعار والصور حالياً بيانات عرض. لا يرسل نموذج الدفع الطلبات ولا يحفظ بيانات العملاء، واشتراك البريد تجريبي. يلزم ربط واجهة المتجر بمخزون وطلبات ودفع وشحن حقيقي، واستبدال بيانات التواصل والسياسات ببيانات النشاط التجاري قبل الإطلاق.
